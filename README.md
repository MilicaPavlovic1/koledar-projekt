# ROM-projekt: Izdelava letnega koledarja v Mathematica

## Opis projekta
Projekt se osredotoča na izdelavo interaktivnega letnega koledarja v Mathematica. Namen je prikazati vse mesece, dneve in praznike za poljubno leto ter omogočiti označevanje posebnih dni. Projekt omogoča vadbo uporabe funkcij za datume, grafično predstavitev in osnovno interaktivnost v Mathematica.

## Načrt projekta
- zbiranje in priprava podatkov: določitev mesecev, dni in praznikov  
- prikaz koledarja: ustvarjanje grafične predstavitve celotnega leta  
- dodajanje funkcionalnosti: označevanje posebnih dni, prilagoditev za poljubno leto  
- testiranje in izboljšave: preverjanje pravilnosti datumov in vizualne jasnosti  
- dokumentacija: zapis funkcionalnosti, navodila za uporabo in povezava na GitHub
