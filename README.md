# Izdelava letnega koledarja v Mathematica

V projektu bom izdelala program, ki omogoča generiranje letnega koledarja za poljubno leto. 
Program bo vključeval prikaz mesecev, dni v tednu ter možnost označevanja praznikov. 
Uporabila bom funkcije programskega okolja Mathematica za obdelavo datumov in vizualizacijo podatkov. 
Cilj projekta je izdelati uporaben in pregleden koledar.
